|---|---|---|

## الاختبار
`l8-test.js` 28 فحصاً (ساعة وكاش وهميان) و`l8-e2e.py` 13 فحصاً (كاش حقيقي). كشف الاختبار تعارض اسم دالة مع `pro-ui.js` وأُصلح وأُضيف فحص دائم للتعارض.

## الحدود (صريحة)
- مسح «كل بيانات الموقع» أو تعديل الكود يتجاوز كل ذلك؛ لا حل بلا خادم.
- لم يُنفَّذ: ربط الكود بجهاز/حدّ أجهزة، توقيع `revoked.json`، منع التلاعب بـ`proActive`. تحتاج خادماً أو تعديلاً في أداة إصدار الأكواد عندك (ليست في المشروع).
- الاختبار على Chromium بحجم هاتف فقط.
