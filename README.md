# المكتبة القانونية — صحف وصيغ ونماذج (الإصدار 1.2.0)

فهرس سريع لصيغ المحامي، يفتح أي صيغة مباشرة (معاينة / تحميل) من جوجل درايف، ويعمل كتطبيق على الموبايل (PWA).

## هيكل المشروع
```
index.html        الصفحة الرئيسية
manifest.json     تعريف التطبيق (الاسم، الأيقونة، الألوان)
sw.js             التخزين المؤقت (عامل الخدمة)
icons/            الأيقونات
css/style.css     التصميم
js/config.js      الإصدار + أنواع الصيغ
js/rules.js       قواعد التصنيف: الموضوع والمرحلة والجهة
js/docx.js        قراءة/كتابة Word واكتشاف الفراغات المنقّطة
js/fill.js        واجهة «تعبئة وتنزيل Word»
js/engine.js      محرك البحث الذكي + دمج النسخ المكررة + المرادفات
js/library.js     أقسام الكتب والموسوعات والتشريعات (روابط مجلدات درايف)
js/app.js         منطق الصفحة (البحث، العروض، المفضلة)
data/broken.js    معرّفات الروابط المعطّلة (يولّدها فاحص الروابط)
tools/check-links.js  فاحص روابط درايف (يعمل على جهازك)
data/             الصيغ مقسّمة حسب الفرع (ملف لكل فرع) — الفرع محدد بمضمون الصيغة وعنوانها لا باسم مجلد درايف
```

## الواجهة
- **التصفح:** بطاقات التصنيفات، وزر «تصفّح حسب» لتبديل التجميع (فرع / نوع / موضوع / مرحلة / جهة).
- **كل الصيغ:** شريط أنواع سريع بسطر واحد، وزر ⚙ يفتح نافذة سفلية للتصفية المتعددة (مع أعداد النتائج).
- **المفضلة والأخيرة:** تُحفظ على جهاز المستخدم.
- **البحث:** يتجاهل الهمزات والتاء المربوطة والتشكيل، ويقبل عدة كلمات.
- ملفات الواجهة: `css/style.css` و`js/app.js`.

## إضافة صيغة جديدة
1. افتح ملف الفرع المناسب داخل `data/` وأضف سطراً: `["معرّف ملف درايف","العنوان","رمز النوع"],`
   - المعرّف هو الجزء بين `/d/` و`/` في رابط الملف.
   - رموز الأنواع: g دفوع ومذكرات، k مبادئ وأحكام، n إنذار، a إعلان، d دعوى، r طلب/مستندات، c عقد، m محضر، w توكيل، e إشكال، t تظلم، f نموذج.
2. زِد رقم الإصدار في `js/config.js` وفي `sw.js` (الاسم `siyagh-vX.Y.Z`).
3. ارفع التعديل على جيت هب.

## فرع جديد
أنشئ ملفاً جديداً في `data/` بالشكل `addBranch("اسم الفرع",[ ... ]);` ثم أضف سطر `<script>` له في `index.html` ومساره في قائمة `A` داخل `sw.js`.

## النشر على جيت هب
ارفع محتويات المجلد في جذر المستودع، ثم: Settings ← Pages ← Deploy from a branch ← main / root.

## فحص روابط درايف
المتصفح لا يستطيع فحص درايف، فالفحص يتم بأمر على جهازك (Node 18 أو أحدث):
```
DRIVE_API_KEY=مفتاحك node tools/check-links.js            # الأدق
node tools/check-links.js                                   # بدون مفتاح (تقريبي)
node tools/check-links.js --folders                         # مع مجلدات قسم الكتب
```
مفتاح API: من Google Cloud Console فعّل Google Drive API وأنشئ API key (مجاني). النتيجة: `data/broken.js` (يظهر في التطبيق علامة ⚠️ وتنبيه في نافذة الصيغة) و`tools/link-report.json` (التفاصيل، وأسماء الملفات الحالية في درايف لاكتشاف ما أُعيدت تسميته). بعد التشغيل زِد رقم الإصدار وارفع التعديل.

## تعبئة الصيغ وتنزيلها Word (جديد في 1.2.0)
زر «✍️ تعبئة وتنزيل Word» في نافذة أي صيغة: يكتشف الفراغات المنقّطة (.....) ويعرضها كنموذج مرتّب حسب الكلمة التي قبلها (السيد/، المقيم، المحامي، المحكمة، الدائرة، التاريخ…)، ثم يحفظ ملف Word على جهازك. كل المعالجة داخل المتصفح ولا يُرسَل شيء لأي خادم.
- الأسماء المتكررة (الطرف الأول/الثاني وعناوينهما) تُملأ مرة واحدة وتنتقل لباقي الفراغات المماثلة.
- بيانات المحامي والمكتب والمحكمة تُحفظ على الجهاز، وبيانات القضية تُحفظ حتى زر «مسح بيانات القضية».
- الفراغ الذي يُترك خالياً يبقى منقّطاً كما هو.
- يعمل مع ملفات docx وملفات Google Docs فقط (يُصدَّر إلى docx). ملفات doc القديمة وPDF وRAR/SHS لا تُعبّأ.
- **مصدر الملف:** إن وضعت مفتاح Drive API في `DRIVE_KEY` داخل `js/config.js` يُجلب الملف مباشرة، وإلا يطلب التطبيق من المستخدم اختيار الملف الذي نزّله.
